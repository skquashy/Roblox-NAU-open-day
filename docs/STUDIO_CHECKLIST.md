# Чек-лист прогона в Roblox Studio

Studio запускается вручную. Отмечайте `[x]` прошло, `[!]` не так (допишите, что видели), и присылайте **весь Output**.

## 0. Подготовка
- [ ] `rojo serve` в папке проекта, в Studio: Plugins > Rojo > Connect, в окне синхронизации Accept.
- [ ] Game Settings > Security > Enable Studio Access to API Services включено.
- [ ] View > Output открыт, выбраны все типы сообщений.

## 1. Запуск (Play)
- [ ] В Output есть `[KAI-Roblox] server started` и `[KAI-Roblox] client started`.
- [ ] Нет строк `require failed`, `init failed`, `start failed`, `Campus build failed`.
- [ ] Предупреждение про `rbxassetid://203785492` (текстура SpawnLocation) можно игнорировать.

## 2. Ядро (этап 2)
- [ ] На голове появился цветной головной убор образа.
- [ ] Выйти и зайти снова: данные игрока сохранились (если включён API Services).

- [ ] Все здания видны, над каждым подпись «Корпус N / Building N».
- [ ] Корпус 8 заметно самый высокий (башня), корпус 11 широкий и светлее.
- [ ] Здания не наложены друг на друга и не стоят на улицах. Если стоят, пришлите скриншот сверху.

## 4. Интерфейс (HUD)
- [ ] При первом входе окно выбора образа (6 карточек) и переключатель языка UK/EN. После выбора на голове цветная шапка.
- [ ] Слева сверху монеты (золотая монета «К»), под ними уровень с XP-шкалой, ниже трекер квестов (до 4 невыполненных).
- [ ] По центру сверху «Факультети N/9» с розовой шкалой.
- [ ] Справа снизу кнопки: Квести, Бейджі, Інвентар, Налаштування. Каждая открывает окно, X и клик по затемнению закрывают.
- [ ] Инвентарь: квестовые предметы, косметика с кнопками «Купити за N» / «Одягнути» / «Зняти»; покупка списывает монеты.
- [ ] Налаштування: UK/EN переключает тексты интерфейса сразу.
- [ ] Цвета фирменные: #267CEB, #224597, #9EDFFF, акцент #E8418E. Шрифт запасной (Geologica не загружен).

## 5. Мини-игра ФКНТ «Кіберзахист» (пилот)
- [ ] Павильон ФКНТ западнее корпуса 8, дверь на восток к аллее, дорожка от двери состыкована с аллеей сбоку (бордюры, одна высота). Вывеска «ФКНТ / FKNT» над красным козырьком, красная полоса по крыше.
- [ ] Внутри: голографическая сеть в центре (хаб и 6 узлов), три большие кнопки перед ней (синяя «Встановити патч», красная «Заблокувати IP», чёрная «Перезапустити»), табло статуса над столом, серверные стойки и шлюз «Інтернет».
- [ ] Подойти к пульту у двери: подсказка «Грати / Play», окно сложности. Сложность 1 запускает игру, на кнопках появляется «Взаємодіяти».
- [ ] На узлах появляются угрозы: ☠ Вірус, ⛔ Атака з IP, ⚠ Збій системи с полоской времени; луч к узлу красится и мигает.
- [ ] Нужная кнопка снимает угрозу (зелёная вспышка), неверная или пропущенная угроза снижает «Статус: N% безпеки» на табло и в панели вверху экрана.
- [ ] По таймеру (70 с) или при нуле безопасности окно результата, награда, бейдж и квест при результате не ниже 60%.
- [ ] Выход и уход от павильона отменяют игру, угрозы исчезают, кнопки перестают реагировать.
- [ ] Повторная победа даёт примерно четверть награды, после первой победы открывается сложность 2.
