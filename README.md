# KAI Open Day: день відкритих дверей КАІ в Roblox

Онлайн-день відкритих дверей Київського авіаційного інституту у вигляді гри в Roblox. Абітурієнт гуляє віртуальним кампусом, заходить у лабораторії факультетів, проходить мініігри, виконує квести, збирає бейджі та монети.

Я хотів зробити так, щоб знайомство з університетом було цікавим: не презентація з буклетом, а місце, де можна походити, подивитися й спробувати.

## Що вже є

- **Кампус** за офіційною схемою території: корпуси 1, 8 і 11 зовні (у стилі Roblox), площа з пам'ятником-літаком Ан-26, парк, проспект Гузара з трамвайною лінією, супермаркет, кіоск, алеї, тротуари та міська панорама Києва навколо.
- **9 факультетів** за списком приймальної комісії: АКФ, ГМФ, ФАЕТ, ФАБД, ФКНТ, ФМФМ, ФНЗ, ФПМВ, ФТЛ.
- **Інтерактивна мінігра ФКНТ «Кіберзахист»**: у лабораторії голографічна мережа з шести вузлів, на яких з'являються загрози (вірус, атака з IP, збій системи). Потрібно вчасно натиснути правильну кнопку: патч, блокування IP або перезапуск. Є три рівні складності.
- **Ігрова система:** вибір образу, монети, рівні й досвід, квести, бейджі, інвентар і магазин косметики.
- **Дві мови:** українська (основна) та англійська.
- **Збереження прогресу** гравця.

## Що ще попереду

- Інтер'єри корпусів 1, 8 і 11 (чекаю на фото інтер'єрів).
- Мініігри решти восьми факультетів, у міру отримання матеріалів.
- Фінальний екран зі студентським квитком і «Ваш наступний крок».
- Мінікарта, звуки, ефекти, офіційні тексти та англійські назви факультетів.

## Як це влаштовано

- **Мова:** Luau (`--!strict`), синхронізація зі Studio через [Rojo](https://rojo.space).
- **Сервер головний.** Досвід, монети, квести, бейджі та результати мініігор рахує лише сервер, клієнт тільки показує стан і надсилає запити. Усі ремоути оголошені в одному місці (`src/shared/Remotes.luau`), кожен обмежений за частотою й перевіряється.
- **Увесь текст через Locale** (`src/shared/Locale/uk.luau` та `en.luau`), без рядків у коді.
- **Кампус будується кодом** з деталей Roblox, без зовнішніх моделей (`src/server/World`).
- **Мініігра = модуль місії** в `src/server/Missions`, яку запускає система `Minigames`.

```
src/shared   конфіг, дані, переклади, типи, ремоути
src/server   системи (збереження, прогрес, квести, мініігри), світ, місії
src/client   інтерфейс (HUD, вікна, мініігра)
docs/        план робіт і чек-лист перевірки в Studio
reference/   схема кампусу та фото корпусів, з яких я будую
```

## Запуск

1. Встановіть інструменти: `rokit install` (Rojo, Selene, StyLua).
2. У теці проєкту виконайте `rojo serve`.
3. У Roblox Studio підключіть плагін Rojo (Plugins → Rojo → Connect) і натисніть Play.
4. Пройдіть [чек-лист](docs/STUDIO_CHECKLIST.md).

Перевірки перед змінами:

```bash
python scripts/check_locale.py
python scripts/check_static.py
selene src
stylua --check src
```
